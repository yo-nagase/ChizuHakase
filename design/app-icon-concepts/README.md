# App icon artwork

The selected shipping artwork for **めざせ！ ちずはかせ** is:

- `concept-04-pop-03-raised-sticker.png`

It uses a raised collectible-card treatment with a warm cream background,
sky-blue card face, orange Japan sticker, gold sparkles, and thick plum outlines.
The artwork contains no text and remains readable at small app-icon sizes.

Run `python3 tools/build_app_icon.py` from the repository root to resize this
source artwork to the 1024×1024, non-transparent PNG used by the asset catalog.
