## App Review メモ（保存予定の全文）

バージョン3.1ではGame Centerのランキングと端末内の個人記録を追加しています。日本7ステージ・世界19ステージの各2出題モード、計52 Leaderboardを利用します。

確認手順：
1. タイトル画面で日本または世界を選び、ステージ選択画面からランキングを開きます。クイズ結果画面からも開けます。
2. 「じぶんの きろく」はサインイン不要です。クイズを遊ぶと正解数と回答時間が端末内に保存されます。
3. 「みんな」→「Game Centerで さんかする」でGame Centerにサインインします。参加前に、ニックネームと記録が公開されることを表示します。
4. 参加・サインイン済みの状態で新しくクイズを開始し、最後まで回答すると、対象ランキングに自己ベストを送信します。参加前の記録や途中でアプリが非アクティブになった回は送信しません。
5. 「きろくの そうしんを とめる」で今後の送信を停止できます。

順位は初回正解数を優先し、同数なら回答時間が短い順です。Game Centerには複合整数のランキングポイントを送信し、アプリ内では正解数と回答時間に戻して表示します。世界全体の平面地図と地球儀は同じLeaderboardを利用します。

アプリ独自のアカウント登録やログインはありません。Game Centerに参加しなくても、クイズ・カード集め・個人記録を利用できます。本番ビルドでは幻カード機能は無効です。通常のシルバー・ゴールド・にじいろカードは利用できます。
