# 世界地図版(せかいの ちず)— 統合方針と分岐設計

日付: 2026-08-16
状態: **計画のみ(未実装)**。方向性の合意を記録する文書。
実装着手前に §4 の未解決課題を決めること。

## 1. 結論: 別アプリにせず、同一アプリに統合する

ただし前提条件がある。**世界版が「今と同じ日本の子ども向け(日本語 UI・
ひらがな中心)」である限り**、の統合判断。海外市場向けにローカライズした
世界版を作る場合は別プロダクトであり、その時は別アプリとして設計し直す
(CLAUDE.md §1「英訳ブランドで英語アプリに見せない」と混ざるため)。

### 理由

| # | 理由 | 補足 |
| --- | --- | --- |
| 1 | **別アプリだと既存ユーザーに届ける手段がない** | Kids カテゴリの「アプリ外リンクを作らない・ペアレンタルゲートを置かない」制約(CLAUDE.md §1, §8)により、既存アプリ内から新アプリへの導線が原理的に作れない。世界版はストア検索だけでゼロから発見されることになる。同一アプリならアップデートで全員に届く |
| 2 | **「ちずはかせ」は日本地図限定の名前ではない** | 「にほんの ちず」と「せかいの ちず」の 2 冊を持つ博士、という拡張は自然。英語ストア表記のサブタイトル(*Japan Map Quiz for Kids*)は公開後でも変更できる(固定なのは bundle ID のみ) |
| 3 | **継続動機の設計と噛み合う** | マイマップとカードの積み上げが継続の軸。その積み上げがある場所に新しい地図が増える方が強い。ずかんに「せかいのカード」の空きマスが現れること自体が動機になる |
| 4 | **コード共有が最大化される** | 地図描画・ヒットテスト・ZoomPan・GameRules・カード抽選・セーブのマイグレーション機構をすべて流用。別アプリはストア運用(スクショ・審査・プライバシーラベル・レビュー獲得)が恒久的に 2 倍になる |

## 2. 分岐設計: タイトル 1 カ所だけに置く

**タイトル画面を「アルバムのページ」として にほん / せかい の 2 ページにし、
そこで選んだ「ちずちょう(アトラス)」を下の全画面に引き回す。**
それより下の画面には二度と分岐を作らない。

```
タイトル(ページ式: にほんの ちず ⇄ せかいの ちず)★分岐はここだけ
 ├ あそぶ → ステージせんたく(そのちずちょうのステージ一覧)
 │            └ モード切替(ちずでさがす / なまえをあてる)← 今のまま
 ├ おぼえたタリー → マイマップ(そのちずちょうの地図)
 └ カードタリー → ずかん(そのちずちょうのカード)
```

### なぜタイトルか

- **タイトルアートの設計がそのまま世界に効く。** 現在のタイトルは
  「自分の進捗(習熟色の日本地図)が飾ってある」画面(`TitleView.miniMap`)。
  世界ページも同じ構造(世界のシルエットが緑に染まっていく + タリー)に
  すれば、ページをめくった瞬間に「こっちの本はまだ白い」が伝わる
- **分岐を 1 カ所にしないと、5 歳児がトグルの状態を追えない。**
  ステージ選択やずかんの中に切替を置くと、同じ切替が 3 画面に散らばり、
  「いま自分がどっちの本にいるか」を画面ごとに確認させることになる。
  CLAUDE.md §5「マイマップを 2 面に分けると 5 歳児には把握できない」と
  同じ理屈で、**面を分けるなら本ごと分け、本の中では一切分岐させない**
- **既存リストへの混載は破綻する。** ぜんこくチャレンジの隣にヨーロッパが
  並ぶと縮尺の世界観が混ざり、マイマップが 1 枚の地図で表現できなくなる

### UI の要点

- スワイプだけだと子どもには見つからない。**ページ端に見えるボタン
  (「せかいの ちずへ →」等)またはタブを置く**
- 前回開いていたページを記憶し、次回起動はそのページから始める
- 設定(⚙️)・効果音・音楽は全体共有のまま(ページに属さない)

### 分岐を置いてはいけない場所

- **クイズモードの階層。** ちずでさがす / なまえをあてる は「出題の向き」で
  アトラスと直交。今の位置(ステージ選択上)のまま両アトラス共通
- **マイマップ・ずかんの内部。** どっちの本のものを見るかはタイトルで
  決まっている。本の切替はタイトルに戻る(ページをめくる)ことでやる

## 3. 実装方針

- **`Atlas`(ちずちょう)を 1 つの値にする**: mapData + stages + cards +
  音声入力語彙の束。`AppState` が japan / world の 2 つを持つ
- **`RootView.Route` の各ケースに atlas を足す**(または選択中 atlas を
  `RootView` の `@State` に置く。`quizMode` と同型のセッション状態)
- **View はアトラス非依存のまま保つ。** `PrefectureMapView` /
  `PrefectureGeometry` / `ZoomPan` は rings と codes しか見ていないので、
  世界データを食わせるだけで動く。分岐はデータ(Atlas)に閉じ込める
- **日本ハードコードの置換箇所**: `Stage.all`、タイトルの `Array(1...47)` と
  タリーの `47`、`MasteryStyle.appearance(for:save:)` の習熟参照、
  `VoiceInputService` の語彙(47 県名 → アトラスごとの語彙)
- **SaveData v6 でアトラス名前空間化**: 現行の `mastery` / `cards` /
  `rainbow` / `streaks` / `records` を `atlases["japan"]` へ移す
  マイグレーションを `SaveData.init(from:)` に足す(v1→v5 と同じ路線)。
  カード ID「01-1」はアトラス内で閉じるので世界カードと衝突しない。
  `settings` は全体共有のまま
- 世界の国コードはアトラス内で完結する Int(ISO 3166-1 numeric 等)。
  日本の県コード 1–47 とは名前空間が分かれるので衝突しない

## 4. 未解決の課題(実装前に決める)

分岐設計より重い 2 つの判断(★)は 2026-08-18 に決定した(§6)。
残るのは実装寄りの課題。

- **除外する極小国の線引き。** §6「タップが成立しない国は収録外」の
  具体リスト化。ズーム最大時のスクリーン寸法から機械的に判定し、
  インセット(沖縄方式)で救う小国(シンガポール等)の選定もここで行う
- **大陸内のステージ分割。** アフリカ 50+ カ国・ヨーロッパ 40+ カ国を
  1 ステージにすると全国チャレンジ級の密度になる。データ裏付きの 18 ステージ案を
  `2026-08-18-world-stages.md` に起こした(たたき台・未確定)
- **世界地図データのパイプライン。** Natural Earth 等 → `build_map_data.py`
  の一般化。出典表記の追加(現在は国土地理院のみ)。沖縄インセット相当の
  処理(遠隔領土・アラスカ等)をどうするか
- **国名のひらがな表記。** 「あめりか」「べとなむ」等の表記決め。読み上げ・
  音声入力の表記ゆれ吸収(「あめりか」「あめりかがっしゅうこく」)も同時に
- **記録全削除のスコープ。** アトラス単位か全体一括か。誤操作を考えると
  「全体一括 + 2 段階確認」のままを推奨

## 5. カード構成(2026-08-18 決定)

**1 国につき 2 枚: 国旗カード + オリジナルカード。獲得順は固定で、
国旗が先、オリジナルが後。**

| # | カード | 獲得タイミング | 制作 |
| --- | --- | --- | --- |
| 1 | 国旗カード | その国の 1 回目の正解 | 国旗画像から生成(手描き不要) |
| 2 | オリジナルカード | 国旗カードがシルバー(★5)に達した後の正解 | 手描き 1 枚(日本版の特産品カード相当) |

**オリジナルカードは国旗カードがシルバーになるまで手に入らない**
(2026-08-18 追加決定)。それまでの正解はすべて国旗カードの星になり、
国旗が ★5 に触れた次の正解でオリジナル ★1 が渡る。両方を持った後は
日本版と同じ「★10 未満からランダムに星 +1」(★10 ゴールド・虹の規則も共通)。
1 国 2 回出題(§6)なら、ノーミスで 3 周目の 1 問目にシルバー、同じ周の
2 問目でオリジナル — 「そのあと手に入る」の 2 段目が必ず後の周に来る。

### なぜ 2 枚 + 固定順か

- 手描き制作量が「国数 × 1 枚」に収まる。全カ国 × 3 枚 ≈ 600 枚の
  非現実性(旧 §4 ★)への回答
- 国旗は子どもが最初に覚える国のシンボルであり、学習順(まず国旗で国を
  知る → 次にその国の中身を知る)と獲得順が一致する
- 図鑑が 1 国 1 マスの薄さにならず、「次はオリジナルがもらえる」という
  2 段目の楽しみが残る

### 規則の差分(日本版との違いは抽選だけ)

日本版の抽選「未所持のカードがあれば、その中からランダムに 1 枚」を、
世界版では「**国旗カードを先に渡し、国旗がシルバー(★5)未満のあいだは
オリジナルを抽選対象に入れない**」にする。星の増やし方・段位・虹はそのまま。
この差分は Atlas(§3)の属性として持たせ、`GameRules` の抽選関数に渡す形に
する(view には出さない)。国旗カードの「あと ◯かいで」文言(`NextGoal`)は
シルバーまでの間「あと ◯かいで オリジナルカード!」を兼ねられる —
シルバー到達とオリジナル解放が同じ出来事なので、予告が二重にならない。

### カード ID

日本版と同じ「{国コード}-{連番}」で、`-1` = 国旗、`-2` = オリジナル。
連番が獲得順と一致する。ID はセーブキーなので公開後は変更しない(§1 と同じ)。

### 未決(§4 に残る)→ 解消済み(2026-08-21・P8 裁定)

- ~~国旗画像の出所とライセンス表記~~ → **不要**。国旗は地域指標記号(絵文字)で
  端末フォントが描くため、画像素材が存在しない(P8 計画・裁定 4)
- ~~シルバー未満のあいだ、図鑑のオリジナル枠の見せ方~~ → **「❓」のまま**。
  空きマスがすでに「もらえる物がある」ことを語っており、「どうすれば」は
  国旗札の「あと ◯かいで オリジナルカード!」が言う(P8 計画・裁定 2)。
  あわせて「オリジナルは手描きができてから足す」も改めた — 題材が作画指示
  そのものなので**題材(絵文字先行)が先、絵は後続バッチ**(裁定 1。日本版が
  絵文字のみで出荷し絵を後から足した前例に従う)

## 6. 収録範囲とステージ(2026-08-18 決定)

- **収録はほぼ全カ国(約 200・国連加盟国ベース)。** ただしズームしても
  タップが成立しない極小国(バチカン、モナコ、太平洋・カリブの微小島嶼国
  など)は収録外とし、専用の救済メカニズムは作らない。地図には背景として
  描く。シンガポール級の「小さいが外せない」国はインセット(沖縄方式)で
  拡大する。オリジナルカードの手描きは約 200 枚 — 日本版 141 枚を超える
  最大の制作項目になることを了解の上での判断
- **総合ステージ「ワールドチャレンジ」を作る**(同日改訂)。当初は
  「約 200 カ国を 1 画面は成立しない」ため大陸のみで開始としたが、
  地球儀モード(§7)の採用で前提が変わった: 総合ステージは
  **地球儀モードと平面地図モードを切り替えられる**ことを本体とする。
  平面 1 枚で成立させる必要がなくなったので総合ステージは成立する
- **出題回数は日本版と同じ 1 国 2 回。** カード 2 枚が初回で同時にそろう
  問題は §5 のシルバー解放ゲートが解決するため、出題規則は共通のまま

## 7. 地球儀モード(2026-08-18 決定)

**正射図法(オルソグラフィック)による擬似 3D の地球儀を実装する。**
SceneKit / RealityKit は使わない — 緯度経度を「球を横から見た円盤」へ
投影する純関数を足すだけで、描画は既存の Path + even-odd、習熟色は
`MasteryStyle.fill` をそのまま使う。新規依存ゼロ(§1 の制約に触れない)。

### 使いどころ

| 画面 | 役割 |
| --- | --- |
| **ワールドチャレンジ** | **地球儀モード ⇄ 平面地図モードの切り替え式**(§6)。切り替えは表示モードであり出題状態を変えない(問題・スコア・れんぞくは持ち越す)。ズームトグルと同格の UI で、分岐(§2)には数えない |
| 世界版マイマップ | 緑に染まっていく地球儀。回して自分の緑を探すこと自体がごほうび |
| タイトル(せかいページ) | ミニ地球儀で進捗を飾る(`TitleView.miniMap` の世界版) |

### 操作と挙動

- ドラッグで回転(投影中心の移動)。地平線(中心から 90° 超)の国は描かない
- ピンチズームは `ZoomPan` を流用
- Reduce Motion: 自動回転(あれば)を止める。ドラッグ起点の回転は
  ユーザー操作なので残してよい
- タップ判定は投影後のスクリーン座標で既存の `contains` + タップ許容。
  ただし**地平線際は前縮みでタップ不能**になるので、出題対象が端に
  ある場合の救済が要る(下記・未決)

### データへの制約(§4 パイプラインに直結)

世界データは日本版のような平面正規化で焼き込まず、**緯度経度を JSON に
保持して投影を実行時に行う**。平面ステージ用の投影も同じ元データから
実行時(またはロード時)に導く。ここが日本版パイプラインとの最大の分岐点。

### 未決

- **裏側・地平線際のヒント。** 3 回ミスの輪郭点滅(§5 日本版)が地球の
  裏側だと見えない。ヒント発動時に正解国を正面へ回す、等の救済
- 地球儀モードでの `nameIt`(赤わく提示)は、対象国を正面に回した状態で
  出題する必要がある(回さないと問題が見えない)

## 8. ワールドチャレンジの出題設計(2026-08-18)

**毎回 47 問。全収録国(約 170)から「まだ出題していない国」を優先して抽選する。**

- 1 プレイ = 47 問・1 国 1 回。47 は日本版の全国チャレンジと同じ長さで、
  子どもが 1 セッションで走り切れることが実証済みの上限。星のしきい値も
  `ceil(47/4)` で日本版と同値になり、`GameRules.stars` がそのまま使える
- 抽選は**未出題優先**: そのモードのワールドチャレンジでまだ出していない
  国から先に取り、足りない分だけ出題済みから足す。カード抽選の
  「未所持があれば、その中からランダム」(§5 日本版)と同じ原理 —
  **網羅を先に、ランダムはその中で**。約 4 プレイで全収録国に一巡し、
  出そろったら履歴をリセットして 2 周目に入る
- 出題履歴はモード別の `Set`(国コード)としてワールドのセーブに持つ。
  習熟から導かない — 習熟はモード共有かつ大陸ステージでも動くので、
  「チャレンジで出したか」の記録にはならない
- スコア・コンボ・星・習熟・カード・れんぞくは通常規則のまま。毎回同じ
  47 問制なので、ベスト記録(星・スコア)の比較も成立する

### 不採用にした案(理由つき)

- **途中セーブで約 170 問を 1 本にする**: 「書き込みはステージ終了時のみ」
  (§6 セーブ)を崩す上、中断・再開の UI を 5〜9 歳に説明できない
- **大陸ごとの区切り(世界一周の章立て)**: 大陸ステージの再放送になり、
  総合ステージの意味(どこが出るか分からない)が薄れる。「世界一周した」
  達成感は、マイマップの地球儀が全部緑になることが担う
