# カード絵追加: 第5バッチ

2026-08-14 実施。内蔵 `imagegen` で石川〜愛知の未作成カード10枚を生成した。
江戸切子・兼六園・鶴ヶ城のカードをスタイル参照に使用。

## 共通プロンプト

- 5〜9歳向け都道府県学習アプリの正方形コレクションカード
- 既存カードの文字階層、角丸のご当地カード枠、水彩・色鉛筆、クリーム紙の質感に合わせる
- 小さい都道府県名、大きい題材名、下2/3の主役という構成
- 指定した2行以外の文字、ロゴ、透かし、写真、3Dレンダー、ネオン色は禁止
- カード全体を正方形内へ収め、角外を透明にする

## 透明処理

生成画像はカード内部を保持したまま、共通角丸アルファマスクで正規化した。
原画は1254px RGBA・四隅alpha 0。`build_card_art.py` で480px・192色へ変換する。
