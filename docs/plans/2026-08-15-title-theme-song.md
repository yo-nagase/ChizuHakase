# タイトルテーマソング「めざせ! ちずはかせ のうた」

2026-08-15 作成。タイトル画面で再生するテーマソングの歌詞。

## 方針

- 対象は 5〜9 歳。歌詞はひらがな中心、1 行 7〜8 音+5〜6 音の童謡リズムで
  歌って覚えられる長さにする
- アプリ内の語彙をそのまま使う: 「どこかな?」(出題文)、「タッチ」、
  「カード」、「おぼえた」(習熟 Lv5 の状態名)、緑→金の地図、
  ぎん・きん・にじいろ(カード段位)
- §12 の思想を歌詞でも守る: 失うもの・急かすもの・叱るものを歌わない。
  「まちがえたって だいじょうぶ」「もういっかいで だいせいかい」と肯定形で返す
- 特産品は実在の札に合わせる(かに=北海道、りんご=青森、さくらんぼ=山形)
- コール&レスポンス(かっこ内)を入れて、子どもが合いの手を入れられるようにする

## 制作・実装メモ(歌詞の外の話)

実装済み (2026-08-15)。原曲は `assets/music/theme-song.mp3`(ローカル限定、
git に入れない)。同梱用はこれを AAC に落としてコミットする:

```bash
afconvert -f m4af -d aac -b 128000 -q 127 \
  assets/music/theme-song.mp3 ChizuHakase/Resources/theme-song.m4a
```

- 再生は `MusicService`(タイトル専用、ループ、離脱時 0.6s フェード)
- ミュートはタイトル左上のボタン。`Settings.musicEnabled`(既定 true)に
  書き込むので再起動後も維持される。設定シートの「おんがく」も同じフラグ
- `musicEnabled` の追加にバージョン繰り上げは不要だった — `Settings` の
  デコードは欠けたキーを既定値で埋める方式(`textMode` 追加時と同じ)で、
  v5 のままで旧セーブは「音楽あり」に読める(テスト
  `savesWrittenBeforeTheMusicSettingPlayMusic` で担保)
- ショート版(タイトル用の声の薄いループ)は未制作。作ったら
  `theme-song.m4a` を差し替えるだけでコードは変わらない

- 楽曲はアプリに同梱する(§1: 通信なし)。AAC 128kbps で 30 秒ループなら
  約 0.5MB、フル 90 秒でも約 1.5MB
- 再生は `AudioSession` の ambient + mixWithOthers のまま
  (消音スイッチに従う。おもちゃとして正しい挙動)
- 読み上げ(`SpeechService`)と同時に鳴らさない。タイトルは読み上げが無いので
  衝突しないが、画面遷移でフェードアウトすること
- 設定に BGM トグルを足す場合は `Settings` に `musicEnabled` を追加
  (v5 → v6 マイグレーション。既定 true)
- 生成音楽サービス(Suno 等)で作る場合は商用利用・アプリ同梱が
  ライセンスで許可されているプランかを確認してから採用する
