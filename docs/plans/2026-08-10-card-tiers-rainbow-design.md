# カード段位の改定: 銀5・金15・虹(れんぞく15)

2026-08-10 承認済み設計。

## 決定事項

### 段位ルール

- ★は現行どおり「同じ札を引いた枚数」。上限が ★5 → **★15** になる
- 段位: ★1–4 ふつう / **★5–14 シルバー** / **★15 ゴールド** / その上に **にじいろ(虹)**
- 抽選は現行のまま: 未所持優先 → ★15 未満からランダム → 全部 ★15 なら「もっている カードだね」
- カード絵は「シルバー以上」のまま。つまり ★5 から絵が出る(旧 ★3 から後退するが、段位基準は不変)

### 虹の条件

- 県ごとに「れんぞく正解数」を持つ。**その県が問題として出たとき**に一発正解で +1、
  つまずいたら(2 回目以降で正解した場合も含む)0 に戻る
- 他の県の問題での誤タップでは切れない(訊かれていないので)
- セッションをまたいで数える。地方ステージは 1 県 2 回出題なので 1 プレイで最大 +2
- **★15(金)の札を持ち、かつ その県のれんぞくが 15 以上** — 両方そろった時点で
  その県の金札すべてが虹へ昇格
- **一度虹になったら戻らない。** れんぞくが切れてもカウンタが黙って 0 に戻るだけで、
  「きれた」とは絶対に言わない(CLAUDE.md §12)

### セーブデータ v4

```swift
var version: Int = 4
var cards: [String: Int]      // ★ 0...15
var rainbow: Set<String>      // 虹に到達したカードID(導出不能なので焼き付ける)
var streaks: [Int: Int]       // 県コード → 現在のれんぞく正解数
```

- 書き込みはステージ終了時のみ(不変)。れんぞくもクイズ中は ViewModel が持つ
- v3 → v4 の★読み替え(段位を取り上げない):
  1→1, 2→2, 3→**5**(銀の下限), 4→**10**(銀区間の中間), 5→**15**(金のまま)
- 旧金札に虹は自動付与しない。虹は「れんぞく 15」の勲章で、まだ誰も達成していない
- `streaks` と `rainbow` は空で開始

### 表示

- カード面の星列は「★12」のような**星 1 個+数字**(15 個は描けない)
- 虹は台紙をホログラフィック箔にする。Reduce Motion では静的なグラデーション
- 進捗文言(ひらがな・肯定形):

| 状態 | 表示 |
| --- | --- |
| ふつう | あと ◯かいで シルバー! |
| シルバー | あと ◯かいで ゴールド! |
| ゴールド | あと ◯れんぞくで にじいろ! |
| 虹 | さいこうの カード! |

- 出す場所: **カード拡大表示**(カードの下に 1 行)と**結果画面の獲得カード欄**
- 未所持のマスには出さない
- タイトル画面などの「キラ」集計(`isSpecial` = 銀以上)の意味は変えない。
  金だけを数えている箇所は「金以上(金+虹)」に揃える

## 実装の切り分け

1. `GameRules`: 定数(銀 5・金/上限 15・虹れんぞく 15)、`nextStreak`、
   虹判定、「あと◯」計算(`NextGoal`)— テスト先行
2. `CardTier` に `.rainbow`、`SaveData` v4 + マイグレーション — テスト先行
3. `QuizViewModel`: 県ごとの出題結果列(clean の順列)を `StageResult` に載せる
4. `SaveStore.applyStageResult`: れんぞく更新 + 虹の焼き付け(catalog を引数に取る)
5. UI: `CardFaceView`(★n 表記・虹箔)、`CardDetailView` / `ResultView` の進捗行、
   `TextMode` の語彙
6. CLAUDE.md §4/§5/§6/§9 を新ルールへ更新
