## アプリの動作

- ステージ選択と結果画面から「ランキング・じぶんの きろく」を開く。
- 自分の記録は端末内の `rankings-v1.json` に保存。既存の学習セーブを変更しない。
- 全体ランキングは参加ボタンで送信を有効化し、Game Center認証する。
- 初回正解数を最優先し、同数なら回答可能時間の合計が短い順。地方の繰り返し出題も1問ずつ数える。
- 時計は単調増加時間を利用。正解演出とカード表示中は停止。アプリが非アクティブになった回は個人記録限定。
- 同じ問題の再回答時間は含む。既存のヒント・音声・読み上げは維持する。
- 未完了の回は順位を付けず「とちゅうまでの きろく」に表示する。
- 参加中かつサインイン済みで開始した回だけ送信候補。ゲスト時代の記録を後から別アカウントに付けない。
- 失敗した送信は起動・復帰・完了・ランキング表示時に再試行。開始時のアカウントと一致する場合のみ送信。
- 各ユーザー・各ボードの最高記録のみ送信。完全同点は同じ送信値になる。
- 個人記録は端末内で共有。端末間同期は今回の範囲外。
- 全体はトップ100と自分の順位を表示する。
- コース選択の各看板にも、選択中の出題モードでの自分の全期間順位を表示する。日本・世界のそれぞれに対応。
- コース選択では自分のエントリーだけを取得する。未参加・未サインイン・記録なし・取得失敗を区別し、画面表示・モード変更・アプリ復帰・下方向への引っ張りで再取得する。
- モードやアカウントを切り替えた場合、前のリクエストの順位を表示しない。コース選択から自動で参加やサインインは行わない。

### 設定値と公開前の確認

1. App ID `com.wakuwaku.chizuhakase` でGame Centerを有効化し、必要ならプロビジョニングを更新。
2. JSONの `id` をLeaderboard IDに使用。IDはコードと完全一致させる。
3. Type = Classic（全期間）、Submission Type = Best Score、Sort Order = High to Low。
4. Score Format = Integer。最小値0、最大値はJSONの `maximumScore`。
5. 日本語表示名はJSONの `name`。アプリ内画面は複合値を「正解数／問題数・秒」に復号して表示。
6. Game Center標準画面には複合整数が表示されるため、単位は「ランキングポイント」とする。
7. Sandbox実機でサインイン、初回送信、自己ベスト更新、再送、アカウント変更、制限されたアカウントを確認。
8. 公開するアプリバージョンにランキングを紐付ける。実際の送信内容に合わせ、プライバシー説明とストア申告も確認。

複合値 = 初回正解数 × 86,400,000 + 86,399,999 − 回答ミリ秒。
24時間以上の回は時間を丸めず個人記録限定（プレイ制限ではない）。問題数または出題ルールを変更する場合は別IDにする。
ローカルスコアのサーバー検証は行わないため、改造端末によるスコア改変を検知する仕組みは今回含めない。
